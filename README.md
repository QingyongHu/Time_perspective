# Time Perspective Self-Assessment

**时间观自评量表** — An interactive self-assessment tool based on the Short Zimbardo Time Perspective Inventory (SZTPI-15).

## About

This tool was developed for classroom teaching in psychology courses at The Chinese University of Hong Kong, Shenzhen. It allows students to assess their time perspective profile across five dimensions:

- **Past-Positive (过去正性)**: Nostalgic, warm view of the past
- **Present-Hedonistic (现在享乐)**: Living in the moment, seeking pleasure
- **Future (未来导向)**: Planning, goal-oriented behavior
- **Past-Negative (过去负性)**: Traumatic or negative view of the past
- **Present-Fatalistic (现在宿命)**: Feeling helpless, external locus of control

The tool calculates the Deviation from Balanced Time Perspective (DBTP) score and provides personalized, encouraging feedback based on research findings.

## Usage

Simply open the page and answer 15 questions using a 5-point scale:

1. Very untrue (完全不符合)
2. Untrue (不太符合)
3. Neutral (中立)
4. True (比较符合)
5. Very true (非常符合)

Results are displayed immediately, including:

- Individual dimension scores with ideal values and gaps
- Radar chart comparing your profile to the balanced TP ideal
- DBTP score with interpretation
- Personalized feedback and suggestions

## Technical Details

- **Single static HTML page** — No backend, no data collection
- **Mobile-responsive design** — Works on phones and computers
- **System fonts** — Fast loading in China
- **Chart.js** for interactive visualizations
